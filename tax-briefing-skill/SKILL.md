# 세무 기한관리 자동 브리핑 (구민이 스킬)

## 목적
"사람 기억"이 아니라 시스템이 기한을 관리한다. 반기 원천세 승인신청(6월·12월)처럼
알림이 따로 없는 **신청형 항목의 누락 방지**가 최우선 목표.

## 폴더 구조
```
tax-briefing-skill/
├── SKILL.md                  ← 이 파일
├── scripts/
│   ├── briefing.py           # 브리핑 생성 엔진 (핵심)
│   ├── biz_status.py         # 국세청 상태조회 → 과세유형·폐업 자동 감지
│   └── holidays.py           # 공휴일 캐시 (기한 순연 정확화)
└── data/
    ├── 거래처.csv            # 거래처명·사업자번호·태그·메모·담당자 (단일 진실 원천)
    ├── 세무일정마스터.json    # 연간 일정 + 매칭규칙 (tags=OR / all=AND / excl=제외)
    ├── config.json           # 경로·API키 설정
    ├── 완료기록.csv          # 완료 처리된 key 목록
    ├── 공휴일.json           # holidays.py가 생성 (선택)
    └── 상태변경리포트.md      # biz_status.py가 생성 → 브리핑에 자동 첨부
```

## 트리거 → 행동

| 사용자 입력 | Claude 행동 |
|---|---|
| "브리핑" / "오늘 브리핑" / "세무일정 확인" | `python3 scripts/briefing.py` 실행 → 결과 요약해서 보여주기 (긴급 건 최상단) |
| "OO 완료 처리" / "부가세 확정 끝났어" | 해당 항목의 `key`를 `data/완료기록.csv`에 한 줄 추가 (key,오늘날짜) 후 브리핑 재생성 |
| "OO 거래처 반기납부 태그 붙여줘" | `data/거래처.csv`에서 해당 행의 태그 열에 `;반기납부` 추가 (상충 태그 규칙 준수 ↓) |
| "거래처 상태 조회" / "폐업 확인" | `python3 scripts/biz_status.py` 실행 → 변경사항 보고 |
| "공휴일 갱신" | `python3 scripts/holidays.py` 실행 |
| "다음 주 일정" / "이번 달 뭐 있어" | briefing.py 결과에서 해당 기간만 필터해 답변 |

## 태그 규칙 (수정 시 반드시 준수)
- 사용 태그: `법인` `개인` `일반과세` `간이과세` `면세` `원천징수` `반기납부` `성실신고` `직원있음` `폐업` `휴업`
- **상충 태그 동시 보유 금지**: 과세유형(일반/간이/면세)은 하나만, 법인↔개인 동시 불가.
  태그 추가 시 상충 태그는 제거할 것.
- 태그 구분자는 세미콜론(`;`). 예: `개인;일반과세;성실신고;직원있음`

## 매칭 로직 (세무일정마스터.json)
- `tags`: 하나라도 보유하면 대상 (OR)
- `all`: 전부 보유해야 대상 (AND) — 예: 성실신고확인 법인세 = `["성실신고","법인"]`
- `excl`: 보유하면 제외 — 예: 종소세 5/31은 `excl:["성실신고"]` (그들은 6/30)
- 세법 개정 시 **이 JSON만 수정**하면 전체 시스템에 반영됨. 코드 수정 불필요.

## 매일 아침 자동 브리핑 (권장 설정)
```bash
# crontab -e  (평일 오전 7시)
0 7 * * 1-5 cd ~/구민이/tax-briefing-skill && python3 scripts/briefing.py
# 매주 월요일 국세청 상태조회 (폐업·과세유형 변경 감지)
0 6 * * 1 cd ~/구민이/tax-briefing-skill && python3 scripts/biz_status.py
```
브리핑 md는 `config.json`의 `vault_briefing_dir`(옵시디언 vault 경로)에 저장되어
Obsidian Daily Note에서 바로 링크·체크 가능.

## 최초 설정 (1회)
1. 이 폴더를 구민이 vault 안으로 복사 (예: `~/구민이/tax-briefing-skill`)
2. `data/config.json`에서 `vault_briefing_dir`를 실제 옵시디언 경로로 수정
3. (선택·강력권장) 공공데이터포털 data.go.kr 무료 API 발급 → config.json에 키 입력
   - 국세청_사업자등록정보 진위확인 및 상태조회 → `nts_api_key`
   - 공휴일은 Google 공휴일 캘린더(ICS)를 키 없이 자동으로 가져오므로 별도 발급 불필요
4. 테스트: `python3 scripts/briefing.py` → md 생성 확인

## 응답 원칙 (구민이 페르소나)
- 브리핑 요약은 긴급(D-7) → 신청기간 진행 중 → 주의 순으로, 대상 거래처 수와 이름 포함.
- 신청형 항목(★)은 기한 30일 전부터 매 브리핑에서 반드시 언급.
- 매칭 거래처 0곳인 일정은 "태그 확인 필요"로 경고 (누락은 침묵이 아니라 경고로).
- 완료 처리 전 반드시 어떤 key인지 확인 후 기록.
